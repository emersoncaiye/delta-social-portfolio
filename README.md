`A content strategy case for Delta (三角洲计划) — a circular space for objects with taste, built for people who move often.`

## 核心判断

- **ICP**：搬得动，但不愿将就的人。三个排除项恰好对应三个竞品的核心用户——人群定义与竞品选择互相印证。
- **第一优先级是抢定义权**，不是涨粉：Delta 极易被误读为「二手店」或「租赁」。
- **把「四道题」（Quiet / Smart / Worth circulating / Usable）从卖点升级为栏目**：竞品在结构上给不出公开标准。
- **把「搬家」从机制理由提升为内容场景**：这是唯一能对齐外部日历（毕业季 / 开学季 / 换约季）的内容节奏。
- **平台适配的代价各不相同**：Pinterest 主动放弃品牌调性换搜索流量，Reddit 主动放弃 CTA 换信任——方向相反，目的是同一个。
